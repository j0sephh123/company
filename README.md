# Summary 
Monorepo for `employees` project that doesn't exist yet

## What is the goal of it?
Several thoughts:
1. I have another app that is more or less doing what i want. I use it a lot on a daily basis and it is very hard for me to continue working on it without distracting myself by using it. When I have a feature that I want, I try to do it very quick, which basically ruins the joy of programming for me
2. I really want the simplest business logic for me. I don't want to have to think about it. I don't want to have to reason about it. I can explain it very clearly and most people know what to expect from the get go as basic functionality. I don't have a company, so I'm not going to want to use it. I can detach myself from a specific feature or functionality, I can simply create requirements and try to accomplish them similar to hook i'm doing in a job.
3. Obviously i have many knowledge gaps (surprise), but i will still use familiar tech - react and some of the node libraries on the backend, because i want to focus on other things that i have very little experience with like auth, deployment, caching and so on. 

## What are some known tech choices
### UI
- React with vite setup - i don't exclude migrating to svelte, but don't want to make this decision right now
- daisyui
- probably either react-query or apollo
- if i need state management it would probably be zustand
- if i need routing i should probably try tanstack router
